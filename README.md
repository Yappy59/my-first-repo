# ぐんぐんノート

ADHDのある8歳くらいの子ども向けの学習アプリです。iPhone・iPadのSafariで開いて「ホーム画面に追加」すると、アプリのように全画面で使えます（App Storeは不要、オフラインでも動きます）。

## 学べること

| コーナー | 内容 |
| --- | --- |
| **カタカナ** | ア〜ノ／ハ〜ン／にている字（シ・ツ・ソ・ン など、見分けのコツつき）／濁音・半濁音／拗音（キャ・シュ…）／ことば→絵／絵→ことば |
| **さんすう 1年** | 10までのたし算・ひき算、くり上がり・くり下がり（10のまとまりのブロック表示）、とけい、文章題 |
| **さんすう 2年** | 2けたのたし算・ひき算（ひっ算、位取りブロックのヒント）、かけ算九九（①2〜5の段 ②6〜9・1の段）、かけ算の文章題 |
| **あなたならどうする？** | 「ADHDってなあに？」（4枚のカード）と、学校・家の12場面のケーススタディ。どれを選んでもやさしい言葉で返し、ためになる「まめちしき」を表示 |

## ADHDの特性に合わせた工夫

- 1回3・5・10問の短いラウンド（設定で変更可）。進み具合が丸で見える
- 答えるとすぐに音と赤いマル。×や減点はなし。2回間違えたら正解を示して次へ
- 最後までやると必ず「はなまる」とシール1枚（全40種のシール帳）
- 20秒の「うごこうタイム」（ジャンプ、のび、深呼吸など）
- 問題文・場面の読み上げ（🔊ボタン）。子ども向けの文はひらがなの分かち書き
- カタカナは教科書体に近い書体で、十字の補助線つきのマス目に表示
- ダークモード対応、動きを減らす設定（視差効果を減らす）に対応
- 「おうちのかたへ」に設定・記録・声かけのヒント

記録（★・シール・クリア状況）はその端末のブラウザの中だけに保存され、外部には送られません。

> このアプリは家庭学習の補助を目的としたもので、医療的な診断・治療・助言の代わりにはなりません。

## iPhone・iPadで使う方法

1. `docs/` フォルダをWebに公開します（下のどれか）。
   - **GitHub Pages**: リポジトリの Settings → Pages → 「Deploy from a branch」で `main` ブランチの `/docs` を選ぶ（無料プランではリポジトリを公開にする必要があります）
   - **Netlify Drop**（https://app.netlify.com/drop）や **Cloudflare Pages** に `docs` フォルダをドラッグ＆ドロップ
2. iPhone・iPadの **Safari** で公開したURLを開きます。
3. 共有ボタン →「ホーム画面に追加」。アイコンから全画面で起動できます。

## ファイル構成

```
src/app.html          アプリ本体（HTML・CSS・JavaScriptを1ファイルに）
docs/index.html       公開用のページ（src/app.html から自動生成）
docs/manifest.webmanifest, docs/sw.js, docs/icon-*.png   ホーム画面用の設定・オフライン用・アイコン
tools/build.js        src/app.html → docs/index.html を作るスクリプト
tools/make-icons.js   アイコン画像を作るスクリプト（Playwright使用）
```

## 編集のしかた

問題や場面を増やすときは `src/app.html` を編集してから、次を実行します。

```sh
node tools/build.js
```

- カタカナのことば: `WORDS`（`["ライオン","🦁"]` の形）
- ケーススタディ: `SCENES`（場面の文、選択肢3つ、`good:true` が一番よい選択、`tip` がまめちしき）
- 運動: `MOVES`、シール: `STICKERS`

公開後にアプリを更新したときは、`docs/sw.js` の `VERSION` の数字を上げると、端末の古いキャッシュが入れ替わります。
